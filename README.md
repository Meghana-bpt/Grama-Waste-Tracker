Grama Waste Tracker is an Android-based smart waste management application designed to support cleaner villages and smarter municipal waste collection. The application enables citizens to report waste blackspots by capturing photos, location coordinates, and descriptions, while municipal authorities can monitor complaints in real time through an admin dashboard.

The system integrates Google Maps, Firebase Realtime Database, Firebase Cloud Messaging (FCM), Camera & GPS services, and Google Gemini AI to provide a complete digital waste monitoring ecosystem. Citizens can track live waste collection vehicles, receive arrival notifications, and interact with an AI-powered waste assistant for waste management guidance.

Key Features ✨
📸 Blackspot Reporting
Capture and submit waste complaints with photos, descriptions, and GPS coordinates.
📍 Live Location Tracking
Track municipal waste vehicles in real time using Google Maps integration.
☁ Cloud Data Storage
Store complaints and tracking data securely using Firebase Realtime Database.
👨‍💼 Admin Dashboard
Municipal authorities can monitor all citizen complaints in a centralized dashboard.
🤖 AI Waste Assistant
Powered by Google Gemini AI to provide smart waste segregation and disposal guidance.
🔔 Push Notifications
Receive real-time alerts such as “Waste vehicle arriving in 5 minutes” using Firebase Cloud Messaging.
📱 Responsive Android UI
Optimized for modern Android devices with a clean and intuitive interface.
Tech Stack 🛠
Language: Kotlin
IDE: Android Studio
Database: Firebase Realtime Database
Cloud Messaging: Firebase Cloud Messaging (FCM)
Maps & Location: Google Maps SDK + Fused Location Provider
AI Integration: Google Gemini API
Image Capture: Android Camera API
Objective 🎯

To bridge the gap between rural citizens and municipal waste management systems by providing a real-time, intelligent, and user-friendly platform for waste reporting, vehicle tracking, and smart environmental monitoring.
